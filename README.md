# ⚡ NexusShop - Full-Stack E-Commerce Web Application

A modern, fully responsive e-commerce web application featuring a complete administration dashboard, built using native PHP, MySQL, JavaScript, HTML, and CSS.

## 🚀 Features
- **User Storefront:** Product browsing grid and item details.
- **Admin Dashboard:** Product inventory management and statistics overview.
- **Database Integration:** Secure database connectivity using PDO and MySQL via XAMPP.
- **Modern UI/UX:** Built with custom CSS variables and responsive design aesthetics.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** PHP
- **Database:** MySQL (phpMyAdmin / XAMPP)
- **Server:** Apache (XAMPP)

## ⚙️ Installation Guide
1. Clone or place this project folder inside your XAMPP `htdocs` directory (`C:/xampp/htdocs/ecommerce-app/`).
2. Start **Apache** and **MySQL** in your XAMPP Control Panel.
3. Open **phpMyAdmin** (`http://localhost/phpmyadmin/`), create a database named `ecommerce_db`, and run the SQL schema setup.
4. Access your application at: `http://localhost/ecommerce-app/index.php`
